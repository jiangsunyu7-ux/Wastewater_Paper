# Stage3G delivery index

All payload ZIPs below24MiB and independently extracted/checked.
Extract Code_and_Reproduce and all Predictions_and_Diagnostics parts into one directory before running reproduction commands.
Quick_Review is the summary; it is not alone a full reproduction.
ARTIFACT_INDEX.json hashes payload ZIPs; PACKAGE_CHECKS.json records actual CRC and extracted member SHA checks.
The index ZIP's own digest is external in SHA256SUMS.txt, avoiding circular claims.
